# 34_Fixed2Excel

## 概要
固定長テキスト（1レコード=1行、バイト位置固定のフラットファイル）とExcelを相互変換するツール。

- **固定長 → Excel**: `configs`内の設定Excel（データ/ヘッダー/トレーラー各シートに開始位置・文字数を定義）を使い、`data/input`の固定長テキストを解析して`data/output`にExcelとして出力する。
- **Excel → 固定長**: `data/output`の（編集済み）Excelを、同じ設定Excelのルールに基づいて固定長テキストへ復元し、`data/recreated_input`に出力する。
- どのファイルにどの設定Excelを適用するかは `data/configs/mapping.csv`（ファイル名に含まれるキーワード ⇔ 設定ファイル名の対応表）で判定する。

設定Excelは1行目=項目名、2行目=開始位置（1始まり）、3行目=文字数 という横並び形式（`データ`/`ヘッダー`/`トレーラー`の3シート、ヘッダー・トレーラーは無くてもよい）。
レコード種別は各行の先頭1バイトで判定する（`config/main.yaml`の`record_type_codes`で変更可）。
出力Excelの「区分」列には先頭1バイトの生コードをそのまま保持しており、Excel→固定長復元時にこの値で先頭バイトを書き戻す（値を消すとその行は復元時に空白バイトになる）。

出力Excelは見やすさのため以下を自動付与する：列幅を内容に合わせて自動調整、ヘッダー行の各項目セルに開始位置・文字数のコメント、レコード種別（ヘッダー/データ/トレーラー）ごとの行の背景色分け、全セルへの罫線、同じレコード種別が2行以上連続する部分の行グループ化（Excelのアウトライン機能で折りたたみ可能）。

## セットアップ
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

## 実行

### GUI（推奨）
```bash
python src/gui.py
```
ウィンドウのボタンから下記4操作を実行する。ログはウィンドウ内に表示される。

### CUI
```bash
python src/main.py
```
メニュー番号を入力して選択する。

いずれも操作内容は共通：

1. **環境初期化** — `data/configs` `data/input` `data/output` `data/recreated_input` を作成し、サンプル設定Excel・サンプル固定長テキストを生成する（初回のみ）
2. **mapping.csv 更新** — `data/input`内の新規ファイル名からキーワード候補を拾い、`data/configs/mapping.csv`に未登録分を追記する（既定の設定ファイル名は要手動確認）
3. **固定長テキスト → Excel 変換**
4. **Excel → 固定長テキスト 復元**

00_ランチャーには「起動（GUI）」「起動（CUI）」の2アクションとして登録済み。

## 注意
- `data/`配下は実データが入るためGit管理外（`.gitignore`対象）。設定Excel・入力ファイルは各自の環境で用意する。
- Excel編集時に項目値前後の空白（パディング）情報は失われるため、値を変更せず往復させた場合を除き、元のバイト列と完全一致することは保証しない（区分コード・項目値そのものは完全に保持される）。
- 対象ファイルをExcel等で開いたまま変換・復元を実行すると、そのファイルだけスキップしてエラーログに出力し、他のファイルの処理は続行する。該当ファイルを閉じてから再実行すること。
