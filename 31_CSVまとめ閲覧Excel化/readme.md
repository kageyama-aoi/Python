# CSV Table Viewer

CSVファイルを読み込み、見やすく整形されたExcelファイル（`view.xlsx`）を自動生成するツールです。phpMyAdminなどからエクスポートしたCSVをそのままExcelで開くと発生する問題（先頭ゼロ消失、列幅崩れなど）を回避し、閲覧に最適な形式で出力します。

## 準備するもの

`csv/` フォルダに **UTF-8** のCSVファイルを置いてください（1CSV = 1シートになります）。Shift-JIS等の別コードのファイルは読み込み時にエラーになります。

```
31_CSVまとめ閲覧Excel化/
    csv_table_viewer.py
    launcher_gui.py
    csv/
        table1.csv
        table2.csv
```

## 出力されるもの

`view.xlsx` が生成されます。

- **INDEXシート**（表紙）… 作成日時、各シート（元CSV）へのハイパーリンク、行数の一覧
- **CSVごとのシート** … ヘッダの黒背景＋白文字、オートフィルタ、ヘッダ行固定、列幅自動調整、長文列は折り返し表示

## 起動方法

```
run.bat をダブルクリック（または 00_ランチャーから起動）
```

GUIランチャー（`launcher_gui.py`）が起動します。Python標準ライブラリ（Tkinter）のみで動作します。

### 画面構成

```
┌────────────────────────────────────────────────────────────┐
│ このツールについて（準備するもの／出力されるもの）             │
├────────────────────────┬───────────────────────────────────┤
│ [左ペイン]               │ [右ペイン]                        │
│  csv/フォルダの内容       │  Log（実行ログ・色付きリアルタイム表示）│
│  ［冒頭を確認］［csvフォルダを開く］［↻］                       │
│  ［▶ 変換実行］［■ Stop］│  出力サマリー（シート数・合計行数）  │
│                          │  ［詳細...］［開く］                │
└────────────────────────┴───────────────────────────────────┘
```

- 左ペインの一覧はダブルクリックまたは「冒頭を確認」で、選択したCSVの先頭10行とエンコードをプレビューできる（実行前に中身を確認したいときに使う）
- 「▶ 変換実行」でサブプロセスとして `csv_table_viewer.py` を実行し、ログをリアルタイムに色分け表示する。終了後、`logs/run_<日時>.log` に自動保存される
- 完了後、出力サマリーに「シート◯件 / 合計◯行」を表示し、「詳細...」で各シート（CSV）ごとの行数一覧、「開く」で `view.xlsx` を直接開ける
- 起動時にすでに `view.xlsx` があれば、その内容をサマリーに読み込んで表示する

### GUIを使わずCLIで実行する場合

```bash
pip install -r requirements.txt
python csv_table_viewer.py
```

## 必要ライブラリ

`requirements.txt` を参照（`pandas`, `openpyxl`）。GUIランチャー自体はTkinter標準ライブラリのみで動作し、`sv-ttk` / `pywinstyles` は任意（入れるとWindows 11スタイルのダークテーマになる）。

## 注意事項

- CSVの文字コードはUTF-8を想定しています（判別できない場合は実行時にエラーメッセージで案内されます）。
- Excelのシート名は31文字制限があるため自動で切り詰められ、重複時は末尾に連番が付きます。
- Excelで使用できない文字は自動で除外されます。
- `view.xlsx` をExcelで開いたまま実行すると書き込みエラーになります。閉じてから再実行してください。
