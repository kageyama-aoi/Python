# CSV Table Viewer

CSV/TXTファイルを読み込み、見やすく整形されたExcelファイル（`data/output/view.xlsx`）を自動生成するツールです。phpMyAdminなどからエクスポートしたCSVをそのままExcelで開くと発生する問題（先頭ゼロ消失、列幅崩れなど）を回避し、閲覧に最適な形式で出力します。

## 準備するもの

`data/input/` フォルダに **UTF-8 または Shift-JIS** の `.csv` / `.txt` ファイルを置いてください（1ファイル = 1シートになります）。区切り文字（カンマ／タブ）はファイルごとに自動判定するため、拡張子が `.txt` のタブ区切りファイルもそのまま置けます。それ以外の文字コード・区切り文字は読み込み時にエラーになります。

```
31_CSVまとめ閲覧Excel化/
    src/
        csv_table_viewer.py
        launcher_gui.py
    data/            ← 実データ・生成物・ログ。丸ごとGit管理外
        input/
            table1.csv
            table2.txt
        output/
            view.xlsx  （実行後に生成される）
        logs/
    run.bat
```

## 出力されるもの

`data/output/view.xlsx` が生成されます。

- **INDEXシート**（表紙）… 作成日時、各シート（元ファイル）へのハイパーリンク、行数の一覧
- **ファイルごとのシート** … ヘッダの黒背景＋白文字、オートフィルタ、ヘッダ行固定、列幅自動調整、長文列は折り返し表示

## 起動方法

```
run.bat をダブルクリック（または 00_ランチャーから起動）
```

GUIランチャー（`src/launcher_gui.py`）が起動します。Python標準ライブラリ（Tkinter）のみで動作します。

### 画面構成

```
┌────────────────────────────────────────────────────────────┐
│ このツールについて（準備するもの／出力されるもの）             │
├────────────────────────┬───────────────────────────────────┤
│ [左ペイン]               │ [右ペイン]                        │
│  data/input/フォルダの内容 │  Log（実行ログ・色付きリアルタイム表示）│
│  ［冒頭を確認］［入力フォルダを開く］［↻］                     │
│  ［▶ 変換実行］［■ Stop］│  出力サマリー（シート数・合計行数）  │
│                          │  ［詳細...］［開く］                │
└────────────────────────┴───────────────────────────────────┘
```

- 左ペインの一覧はダブルクリックまたは「冒頭を確認」で、選択したファイルの先頭10行・エンコード・区切り文字（カンマ／タブ）をプレビューできる（実行前に中身を確認したいときに使う）
- 「▶ 変換実行」でサブプロセスとして `src/csv_table_viewer.py` を実行し、ログをリアルタイムに色分け表示する。終了後、`data/logs/run_<日時>.log` に自動保存される
- 完了後、出力サマリーに「シート◯件 / 合計◯行」を表示し、「詳細...」で各シート（CSV）ごとの行数一覧、「開く」で `data/output/view.xlsx` を直接開ける
- 起動時にすでに `data/output/view.xlsx` があれば、その内容をサマリーに読み込んで表示する

### GUIを使わずCLIで実行する場合

```bash
pip install -r requirements.txt
python src/csv_table_viewer.py
```

## 必要ライブラリ

`requirements.txt` を参照（`pandas`, `openpyxl`）。GUIランチャー自体はTkinter標準ライブラリのみで動作し、`sv-ttk` / `pywinstyles` は任意（入れるとWindows 11スタイルのダークテーマになる）。

## 注意事項

- 対象は `data/input/` フォルダ直下の `.csv` / `.txt` のみです（サブフォルダは対象外）。
- `data/` フォルダは実データ・生成物・ログを含むため丸ごとGit管理外です。初回はGUI（「入力フォルダを開く」ボタン）または実行時に自動で作成されます。
- 文字コードはUTF-8またはShift-JISを想定しています（両方とも判別できない場合は実行時にエラーメッセージで案内されます）。
- 区切り文字はカンマ／タブをファイルごとに自動判定します。それ以外の区切り文字（セミコロン、固定長など）には対応していません。固定長ファイルは `34_Fixed2Excel` や `33_テキスト・CSV前処理サポート/fixed_length_formatter` を利用してください。
- Excelのシート名は31文字制限があるため自動で切り詰められ、重複時は末尾に連番が付きます。
- Excelで使用できない文字は自動で除外されます。
- `data/output/view.xlsx` をExcelで開いたまま実行すると書き込みエラーになります。閉じてから再実行してください。
