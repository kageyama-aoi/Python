# JSON⇒TSV

JSONファイルの階層構造を、パスごとに縦展開したTSVに変換するツールです。会員大会（kaiin_taikai）データの確認用に作成されました。

## 機能

- カレントフォルダ内の最新の`.json`ファイルを自動検出して読み込み
- JSONの各リーフ値までのパス（`courses[0].conditions[1].child.note` のような形式）を抽出
- パスを階層ごとの列に分割し、同じ値が連続する場合は `→` で省略表示
- 出力は `output_{タイムスタンプ}.tsv`
- 同名の古い出力（`output_*.tsv`）は自動で `old/` フォルダへ退避

## 使い方

1. 変換したいJSONファイルをこのフォルダに置く
2. 実行する

```bash
python pg1.py
```

3. `output_{タイムスタンプ}.tsv` が生成される

## ファイル構成

| ファイル/フォルダ | 説明 |
| --- | --- |
| `pg1.py` | 変換スクリプト本体 |
| `old/` | 古い出力の退避先（自動生成） |
| `code_technic.html` / `readme_1209.html` | 過去の作業メモ |

## 注意事項

対象JSONファイルが複数ある場合、更新日時が最も新しいものが自動選択されます。意図しないファイルが変換されないよう、作業前にフォルダ内を確認してください。
