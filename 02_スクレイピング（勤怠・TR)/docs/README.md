# 技術ドキュメント一覧

このプロジェクトで使用している技術の解説集です。
**AI駆動開発で構築したため、ナレッジを後から補完することを目的**としています。

## 読み方ガイド

各ドキュメントは3つのレベルに分かれています。

| レベル | 対象 | 読み方 |
|---|---|---|
| IT新人向け | プログラミング歴1年未満 | 「なぜ使うか」「何をするものか」を理解する |
| 中級者向け | プログラミング歴1〜3年 | 設計判断・コードの読み方を理解する |
| 上級者向け | プログラミング歴3年以上 | アーキテクチャの評価・改善点を考える |
