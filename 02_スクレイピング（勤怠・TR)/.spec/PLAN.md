# crowdlog工数入力補助ツール 引き継ぎ

## プロジェクト概要
crowdlog.jp への工数入力を効率化するPythonスクレイピングツールに、
ブラウザで動作するHTML補助UIを追加統合したい。

## 既存環境
- PythonベースのスクレイピングツールがすでにあるRPAのプロジェクト
- crowdlogへのログイン・操作はSelenium（またはPlaywright）で実装済み
- Googleカレンダーとの連携同期機能あり

## 追加するもの
添付のHTML（crowdlog_input.html）は工数入力補助UIです。
C:\Users\kageyama\Tools\Python\02_スクレイピング（勤怠・TR)\src\crowdlog_dur_input.html
以下の機能が実装されています：

### UI機能
- 2時間ごとのセクション（8-10時 / 10-12時 / 12-14時 / 14-16時 / 16-18時 / 18-22時）に分かれた入力画面
- 各セクションに「＋ この時間帯に追加」ボタンがあり、押すとそのセクション内の空き時間から開始時刻を自動セット
- 作業時間はプルダウン（よく使う値）＋ 隣に直接入力欄（min単位）が並んでいる
- タスクを選ぶとプリセット作業時間が自動セット
- 設定タブでプロジェクト×タスクごとのデフォルト作業時間を管理できる
- 「登録して同期 ↗」ボタンで入力データをバックエンドに送信する想定

### データ構造（UIが出力するJSON想定）
{
  "date": "2025-04-07",
