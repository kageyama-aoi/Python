# 日付付きファイル世代整理

日付サフィックス（`_YYYYMMDD`）付きのファイルが溜まったフォルダを整理し、各ベース名ごとに最新N件だけを残して残りを`old`フォルダへ退避するスクリプトです。

設計書・帳票など「同じ名前＋日付」で世代管理しているフォルダの掃除を想定しています。

## 対象ファイル名の形式

```
{ベース名}_{YYYYMMDD}.{拡張子}
例: 詳細設計書_20251201.xlsx, 詳細設計書_20251208.xlsx
```

同じベース名のファイルをグループ化し、日付降順で`keep`件数だけ残します。

## 使い方

1. `config.example.ini` をコピーして `config.ini` を作成し、編集する

```ini
[settings]
target_dir = 対象フォルダの絶対パス
keep = 3            ; 残す件数
old_dir_name = old   ; 退避先フォルダ名（target_dir配下に作成）
dry_run = true       ; true の間は実際には移動せず、対象一覧のみ表示
```

2. まず `dry_run = true` のまま実行し、移動対象を確認する

```bash
python organize_dated_files.py
```

（または `run.bat` をダブルクリック）

3. 問題なければ `dry_run = false` にして再実行する

## 出力の見方

移動対象があるグループだけをブロック表示し、動きのないグループは末尾に件数のみ集約します。

```
対象: C:\...\08_詳細設計（46ファイル → 14グループ）

【移動対象 2件】

=== 基本設計書.xlsx ===（5世代あり、最新3件を残す）
  移動予定: 基本設計書_20260601.xlsx → old\
  移動予定: 基本設計書_20260525.xlsx → old\

移動なし: 13グループ（keep=3以内）
[DRY-RUN] 移動予定 2件。実際の移動は行っていません（config.ini で dry_run = false にすると実行）
```

## 注意事項

- `config.ini` は実パスを含むためgit管理外です。初回は `config.example.ini` から作成してください。
- 日付部分を含まないファイルは処理対象外（スキップ）です。
- 8桁でも日付として不正なもの（例: `_99999999`）は警告を出してスキップします。
- 退避先 `old` に同名ファイルがある場合は上書きせず、警告を出して移動しません。
