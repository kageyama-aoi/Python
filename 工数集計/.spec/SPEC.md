# SPEC - 技術仕様・要件定義

## タスク1：ISSUE_TEMPLATE の作成

### 概要
`.github/ISSUE_TEMPLATE/` に、このプロジェクト専用のIssueテンプレートYMLを作成する。
コピー元（`02_スクレイピング（勤怠・TR)`）の4ファイルをベースに、コンポーネント選択肢などをこのプロジェクト向けに書き換える。

### 作成ファイル
| ファイル名 | テンプレート名 |
|---|---|
| `bug_report.yml` | 🐛 バグ報告 |
| `feature_request.yml` | ✨ 機能リクエスト |
| `question.yml` | 💬 質問・相談 |
| `task_memo.yml` | 📋 タスク・作業メモ |

### カスタマイズ方針
- `bug_report.yml` の「発生箇所」ドロップダウンを以下に変更：
  - CSV読み込み（タイムシート・TR）
  - データ処理・集計
  - Excel出力・スタイル
  - 設定ファイル（config.json）
  - メイン処理フロー
  - その他
- その他の項目はコピー元を維持（ラベル・タイトルプレフィックスなど）

## タスク2：コード全体把握とリファクタリング案の提案

### 概要
現状コードを分析し、リファクタリング候補を洗い出して優先度付きで提案する。
実装はしない（優先度確認後に別タスクで対応）。

### 分析対象ファイル
- `main.py`（ルート）
- `src/config.py`
- `src/constants.py`
- `src/data_loader.py`
- `src/processor.py`
- `src/excel_writer.py`

### 提案の記載先
`.spec/KNOWLEDGE.md` にリファクタリング候補一覧（優先度・理由つき）を記載する。

---

## 非機能要件
- 既存コードの動作は変更しない（タスク2は提案のみ）
- テンプレートはコピー元の日本語・書式を維持する
